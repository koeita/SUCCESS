# 高校受験・大学受験サクセスゲーム (SUCCESS)

高校3年間の学校生活・部活動・勉強を通じて偏差値を伸ばし、志望大学合格を目指す育成シミュレーションゲームです。

## 主な機能
- **高校3年間（144ターン）育成システム**: 4月から翌年3月まで、勉強・部活・休養・息抜きのコマンドを選択
- **自動偏差値アップシステム**: 各教科（英語・数学・国語・理科・社会）を勉強することで経験値が蓄積され、一定値ごとに偏差値が上昇
- **交友関係・OB名簿システム**: 友人やライバル、合格した先輩（殿堂入り）からの差し入れイベント
- **共通テスト・二次試験バトル**: 3年1月と2月に立ちはだかる試験をコマンドバトル形式で突破
- **合否判定・エピローグ演出**: 志望校レベルに応じた合否判定とエンディング
